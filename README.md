# gfu-schulung

Ein paar Infos zu der Anwendung:

Die Anwendung besteht als zwei Teilen (Backend und Frontend)

Backend starten (in einem eigenen Terminal)  
npm run db:mock

Frontend starten (in einem eigenen Terminal) 
npm run start

Unittests:
npm run test

E2E-Tests mit BDD:
npm run e2e
oder
npm run e2e:ui

Dokumentation erzeugen (in./docs):
npm run docs

Die Anwendung ist dann über http://localhost:4200/ erreichbar.
Über http://localhost:3000/books ist ein Restbackend erreichbar.
