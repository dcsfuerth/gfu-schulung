# gfu-schulung

Die Anwendung besteht als zwei Teilen (Backend und Frontend)

## Backend starten (in einem eigenen Terminal)  
```npm run db:mock```

Über http://localhost:3000/books ist das Restbackend erreichbar.


## Frontend starten (in einem eigenen Terminal) 
```npm run start```

Die Anwendung ist über http://localhost:4200/ erreichbar.


## Unittests
```npm run test```

## E2E-Tests mit BDD

```npm run e2e```
oder
```npm run e2e:ui```

## Dokumentation erzeugen (in./docs):
```npm run docs```
